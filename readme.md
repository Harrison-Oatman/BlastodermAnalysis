# BlastodermAnalysis

## Overview
Figure-generating repo for blastoderm analysis. Contains the code required to load, process, and generate figures for the .h5 files generated by the blastoderm tracking process.

## Installing dependencies

### Using uv
after cloning this repository, run ```uv sync``` inside the repo to install dependencies.

You can then point your IDE to the generated virtual environment. Your IDE might do this automatically.
